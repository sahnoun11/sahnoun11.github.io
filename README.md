Personal blog of **Oussama Sahnoun** — Senior Offensive Cybersecurity Expert, Purple Team Lead, and AI Systems Security Researcher. Live at **[sahnoun11.github.io](https://sahnoun11.github.io)**.

Technical write-ups on penetration testing, threat intelligence, ransomware analysis, and AI/LLM system security — including the [AI Systems Security Specialist](https://sahnoun11.github.io/posts/ai-systems-security-specialist-series-overview/) series and my [Black Hat MEA 2025](https://sahnoun11.github.io/posts/ai-threat-intelligence-blackhat-mea-2025/) talk recap.

## Stack

Built with [Jekyll](https://jekyllrb.com/) and the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy/) theme, deployed to GitHub Pages via GitHub Actions on every push to `main`.

## Local development

```shell
bundle install
bundle exec jekyll serve
```

Site is then available at `http://127.0.0.1:4000`.
